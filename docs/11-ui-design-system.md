# 11 — UI Design System (الإصدار الأول — مُستبدَل)

> **تنبيه:** هذا التصميم الأول (أسود/ذهبي) استُبدل بلغة «خريطة» المعتمدة في [`12-design-system-kharita.md`](./12-design-system-kharita.md) بتاريخ 2026-10-19. يُحفظ هنا للسجل فقط.


## الهوية
**Premium · Minimal · Professional · Fast · Dark.** الشارت هو العنصر الأساسي؛ لا أرقام بلا داعٍ؛ المستخدم يفهم المعلومة بسرعة.

## الرموز (Tailwind `apps/web/tailwind.config.ts`)
| الرمز | القيمة | الاستخدام |
|---|---|---|
| `bg` | `#0b0c0f` | خلفية التطبيق والشارت |
| `bg-panel` / `bg-panel2` / `bg-hover` | `#13151a` / `#191b21` / `#1f2229` | البطاقات، المدخلات، hover |
| `line` | `#2d3038` | الحدود والشبكة |
| `gold` / `gold-light` / `gold-dim` | `#d5b15d` / `#f1d99a` / `#65532c` | التمييز، العناوين، الأزرار الأساسية |
| `ink` / `ink-muted` / `ink-faint` | `#f4f2ed` / `#a9a9b0` / `#6f7079` | النص |
| `up` / `down` | `#37c7a0` / `#f07882` | صاعد/هابط، شموع |
| `info` / `warn` | `#8db7ff` / `#f0b35c` | مستويات الفريم الحالي، تحذيرات |

جودة المناطق: HIGH أخضر `rgba(55,199,160,·)`، MEDIUM ذهبي، LOW رمادي. المحددة تزداد شفافيتها.

## المكونات (classes في `globals.css`)
`.card` · `.btn` · `.btn-ghost` · `.input` · `.label` · `.chip` · `.kbd`.

## التخطيط
- Shell: Sidebar 256px (قابل للطي إلى 64px) · Topbar لاصق مع بحث ⌘K وتبديل اللغة · Footer إخلاء مسؤولية · شريط سفلي على الموبايل.
- Chart workspace: `grid [1fr_320px]`؛ الشارت يملأ الارتفاع؛ Side Panel + AI Chat في العمود الأيمن (الأيسر في RTL).
- Zone Details: بطاقة عائمة أسفل الشارت (لا modal يحجب الشارت).

## RTL/LTR
`dir` على `<html>` يتغير مع اللغة؛ كل المسافات بـ`ps/pe/ms/me/start/end`. الأرقام والرموز بخط monospace.

## الحركة والأداء
بلا حركات زخرفية؛ انتقالات 150ms للـhover فقط؛ الشارت يُحدَّث عبر refs بلا re-render على كل tick.

## الوصولية
تباين ≥ 4.5:1 للنص الأساسي؛ عناصر تفاعلية ≥ 32px؛ اختصارات لوحة المفاتيح (⌘K)؛ عناوين الأزرار `title`.

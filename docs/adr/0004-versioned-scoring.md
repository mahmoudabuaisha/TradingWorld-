# ADR-0004 — أوزان تقييم مُنسَّخة واعتماد بشري للتغيير

**الحالة:** مقبول · **التاريخ:** 2026-10-19

## القرار
- `FACTOR_WEIGHTS` ثابتة في الكود (`scoring/weights.ts`) ومجموعها 100؛ اختبار يضمن ذلك.
- أي تغيير = `SCORING_VERSION` جديدة + سطر في PROGRESS.md §6 + صف في `EngineVersion`.
- الـML (`services/ml`) يُخرج اقتراحات بحالة `proposed`؛ النشر قرار بشري بعد walk-forward lift موجب.

## العواقب
+ كل منطقة قديمة قابلة للتفسير بأوزان زمنها؛ رجوع فوري بتبديل الإصدار النشط.
− لا "تعلم ذاتي" لحظي — وهذا مقصود.

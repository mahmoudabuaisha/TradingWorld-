# ADR-0001 — المحرك حتمي، والـLLM يشرح فقط

**الحالة:** مقبول · **التاريخ:** 2026-10-19

## السياق
المواصفة تشترط ألا يختلق الـAI التحليل، وأن تكون كل منطقة قابلة للتفسير والاختبار والقياس، مع إمكانية Replay/Backtest دون تسريب.

## القرار
- الاكتشاف والتقييم ودورة الحياة والتسمية والشرح الأساسي = خوارزميات حتمية في `packages/analysis-engine` (TypeScript خالص، بلا I/O).
- الـLLM (Claude عبر SDK) يستلم JSON مُهيكلًا (`buildGrounding`) ويُقيَّد بـsystem prompt يمنع الاختراع والتوصيات، ويوجد مُفسِّر حتمي بديل دائمًا.
- كل نتيجة تحمل `engineVersion` + `scoringVersion`.

## العواقب
+ قابلية التدقيق والاختبار وإعادة الإنتاج؛ عمل بلا تكلفة LLM.
− يجب كتابة كل عامل جديد كـdetector (لا "اسأل النموذج").

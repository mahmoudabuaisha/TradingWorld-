# ADR-0005 — اعتماد لغة التصميم «خريطة»

**الحالة:** مقبول · **التاريخ:** 2026-10-19 · **القرار:** صاحب المشروع

## السياق
التصميم الأول (أسود/ذهبي، بطاقات، شريط جانبي) كان مألوفًا ومقتبسًا من منصات الإشارات. صاحب المشروع طلب تصميمًا جديدًا غير مألوف.

## القرار
اعتماد لغة «خريطة» (docs/12): الشارت خريطة والمحرك مسّاح. خمسة ألوان فقط (ميدان/حبر، زنجار، كهرمان، ختم)، عائلة خط واحدة للغتين (IBM Plex Sans Arabic + Plex Mono)، سكة أطالس بدل الشريط الجانبي، كتلة عنوان تحت كل شارت، ورقة ميدان يومية بدل لوحة البطاقات، مناطق مهشّرة باتجاه يحدد الطلب/العرض.

## البدائل المرفوضة
- إبقاء الأسود/الذهبي: مألوف ويوحي بقنوات الإشارات.
- الأخضر/الأحمر المشبع: يسقط عند عمى الألوان والطباعة.

## العواقب
+ هوية مميزة قابلة للتفسير، وصولية أعلى، رموز في ملف واحد.
− إعادة بناء الطبقة التحليلية (المرحلة C) والأوراق المتبقية (D)؛ الاعتياد على زنجار/كهرمان يحتاج خيارًا كلاسيكيًا في الإعدادات.
